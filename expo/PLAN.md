# Исправления: иконка, уведомления, события, авторизация API

## 1. Иконка приложения — смена цвета по теме
- Логотип Envo будет менять цвет: **чёрный** в светлой теме, **белый** в тёмной
- Используется `tintColor` поверх текущего изображения

## 2. Дашборд — точка после "тыс"
- Формат суммы будет исправлен: `7 тыс ₽` → `7 тыс. ₽`
- Также `млн` → `млн.` для единообразия

## 3. Уведомления — исправление бага и формата
- Уведомления будут приходить **только при появлении новой продажи** (не пачками по 4)
- Каждая новая продажа — отдельное уведомление
- Формат текста: **«Новая продажа: Название мероприятия, X билет(а/ов)»**
- Центр уведомлений будет доступен **с любого экрана** (иконка колокольчика в шапке всех вкладок)

## 4. Экран «События» — исправления
- **4.1 Переименование группы**: окно с полем ввода будет корректно отображаться поверх других элементов модального окна
- **4.2 Удаление из группы**: исправлена логика — событие будет корректно извлекаться из группы и становиться отдельным
- **4.3 Календарь**: обводка выбранной даты будет отцентрирована относительно числа

## 5. Авторизация API — ручной ввод
- Логин, пароль и город **не будут подставляться** из переменных окружения автоматически
- При первом запуске поля будут пустыми — пользователь вводит данные самостоятельно
- После сохранения данные запоминаются в хранилище и используются при следующих запусках
